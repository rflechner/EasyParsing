VOTRE PREMIER PARSEUR

Du texte à une valeur C#

using System;
using System.Globalization;
using EasyParsing.Dsl.Linq;
using static EasyParsing.Dsl.Parse;

var decimalParser =
    from whole in ManySatisfy(char.IsDigit)
    from dot in OneCharText('.')
    from fraction in ManySatisfy(char.IsDigit)
    select decimal.Parse($"{whole}.{fraction}",
        CultureInfo.InvariantCulture);

var result = decimalParser.Parse("123.456");

if (result.Success && result.Context.Remaining.IsEmpty)
    Console.WriteLine(result.Result.ToString(
        CultureInfo.InvariantCulture));
Sortie123.456

Ce code utilise uniquement le package EasyParsing.

01

1. Reconnaître

Les deux ManySatisfy capturent les chiffres ; OneCharText reconnaît le point.

02

2. Enchaîner

Chaque from poursuit la lecture avec le contexte du parseur précédent. Un échec arrête toute la séquence.

03

3. Transformer

Le select transforme les captures en decimal. Votre grammaire devient un parseur réutilisable.

Le parsing peut réussir sur un préfixe. Pour exiger une lecture complète, vérifiez aussi result.Context.Remaining.IsEmpty.

Et si plusieurs formes sont possibles ?

Avec A | B, EasyParsing essaie A en premier. Si A échoue, B reçoit le même contexte de départ. C’est ce qui permet le backtracking.

À propos de la fidélité au code EasyParsing +

Cette visualisation exécute une adaptation JavaScript instrumentée du code C# de la branche develop, consulté le 12 septembre 2026. Elle ne charge pas la bibliothèque .NET. Les enveloppes Cast, AsString et les alternatives imbriquées sont regroupées pour rendre les étapes lisibles.

L’exemple JSON accepte les guillemets simples et les booléens sans distinction de casse. Il ne gère pas null, les nombres négatifs ou les exposants ; il ne vérifie pas que tout le texte est consommé. Aucun espace initial n’est ajouté ou supprimé par la démo.

Le comportement actuel de SeparatedBy est conservé : les collections vides et les collections d’un seul élément échouent. Les échappements des chaînes suivent CreateStringParser, et non le standard JSON complet. Une exception de conversion arrête le parsing, sans essayer l’alternative suivante.

Les tableaux directement imbriqués déclenchent une NullReferenceException dans cette version : leur alternative capture ItemsParser avant son initialisation. Une exception arrête le parsing, sans essayer l’alternative suivante.

Limites de la visualisation : 800 caractères, 14 000 étapes, profondeur limitée et décimaux jusqu’à 28 chiffres significatifs / 28 décimales. Les valeurs numériques sont affichées sans passer par les nombres flottants JavaScript.
